# Privacy Policy — NJ Transit MCP Server (unofficial)

## Data collected: none, by design
This server does not require an account, does not ask for your name,
email, location, or payment details, and does not store queries tied
to a person. Tool calls contain only the station/stop names or IDs
you (or your AI client) send in that call, which are needed to answer
that call and are not retained as a profile.

## What the host sees
Like any web service, the host (Vercel) may log standard request
metadata (IP address, time, path) for security and abuse prevention,
including the per-IP rate limiter. Those logs are not sold, not used
for advertising, and not shared except as required by law.

## Third-party feeds
To answer a query, the server fetches public NJ Transit GTFS files
and the community PATH GTFS-Realtime feed. Those fetches do not send
your personal information to NJ Transit or PATH.

## No tracking, no cookies, no analytics in the MCP tools
The MCP endpoint does not set tracking cookies and does not run
analytics on tool calls.

## Contact
Questions about this policy: use the contact details in the public
repository (https://github.com/mir-quadri/nj-transit-mcp).
